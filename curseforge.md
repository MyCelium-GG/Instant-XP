# InstantXP

Never walk over XP orbs again. Every server tick, orbs within a few blocks of
you are picked up instantly, as if you had stepped on them. Silent,
server side, no keybinds.

- Vanilla pickup path: Mending, sounds, stats and the take animation all work
- Dead, removed and spectator players collect nothing
- Config: `enabled` (default true), `radius` (default 8, range 1-64)
- Requires **Mycel**: install it alongside this mod

Reload live with `/mycel reload instantxp`.
