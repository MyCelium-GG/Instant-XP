# InstantXP

Never walk over XP orbs again. Every server tick, orbs within a few blocks of you are picked up instantly, as if you had stepped on them. No keybinds.

![Before: a field full of XP orbs. After: the same field, empty](https://wiki.mycelium-gg.org/instantxp/img/before-after.jpg)

- Uses the vanilla pickup path, so Mending, sounds, stats and the take animation all work
- Pickup radius of 8 blocks by default, from 1 to 64
- Dead, removed and spectator players collect nothing

## Install

Server side: install it on the server, or in your own game for singleplayer.

Requires [Mycel](https://www.curseforge.com/minecraft/mc-mods/mycel): install it alongside this mod. Minecraft 26.1, 26.2 and 26.3 on Fabric, Forge and NeoForge, Java 25. On Fabric you also need Fabric API.

Every setting and command is on the [wiki](https://wiki.mycelium-gg.org/instantxp/).
