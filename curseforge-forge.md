# InstantXP (Forge)

XP orbs are picked up the moment they come close.

Every server tick, orbs within a few blocks of you are collected instantly, as
if you had stepped on them. Silent, server side, no keybinds.

- Vanilla pickup path: Mending, sounds, stats and the take animation all work
- Config: `enabled` (default true), `radius` (default 8, range 1-64)

Requires **Mycel**. Needs Forge 66.0.9+, Minecraft 26.3, Java 25.
